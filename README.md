# Mars Ops: Mission Decision Engine

NASA Space Apps Challenge için geliştirilen, tarayıcıda oynanan 3D Mars misyon karar simülatörü.

Oyuncu bir Mars misyon direktörüdür: roket, güç kaynağı ve bilimsel cihaz seçer, iniş bölgesini belirler ve iki rastgele krizle yüzleşir.

## Çalıştırma
`index.html` dosyasını tarayıcıda açın (internet gerekir: Three.js ve yazı tipleri CDN'den yüklenir).

## Teknoloji
HTML, CSS, JavaScript, Three.js (r128)

Not: Rakamlar NASA misyonlarından (Curiosity, Perseverance, Opportunity, MOXIE) esinlenmiş yaklaşık değerlerdir.
